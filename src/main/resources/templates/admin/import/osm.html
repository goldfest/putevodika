Максимальный размер по умолчанию — 100 МБ для файла и 110 МБ для запроса. Фактические лимиты определяются настройками сервера и прокси.

Требования к формату

  • Только .json с массивом в корне: [{…}, {…}]. ZIP не поддерживается.
  • Каждый элемент должен иметь id, osm, name, categories, location, scores.
  • OSM ID имеет вид osm:node:12345 (также way и relation).
  • Категории должны существовать и быть активными в базе.
  • Все 13 полей scores обязательны, значения — от 0 до 1.
  • Повторный импорт того же OSM ID обновляет существующий объект, а не создаёт дубликат.

Это импорт подготовленных данных, а не загрузка сырого файла OpenStreetMap (.osm/.pbf). Пример JSON находится в комплекте исходников.
